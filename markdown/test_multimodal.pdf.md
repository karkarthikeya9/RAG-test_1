## # Client Server Architecture

The client communicates with the server over HTTP. The application server processes requests, accesses the database when required, and returns a response to the client.

## ## HTTP Status Codes

The server returns the following status codes.

| 200 | 200 OK           |
|-----|------------------|
| 404 | 404 Not Found    |
| 500 | 500 Server Error |
